# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a Vulnerability

Please report security issues privately by email: `zuroking69@gmail.com`.
Do not open public issues for undisclosed vulnerabilities.

Include:
- affected version
- reproduction steps
- impact assessment

You can expect an acknowledgement within 7 days.

## Scope Notes

- pro-autocliker is a local desktop tool: no network access, no telemetry, no accounts.
- Game-specific anti-cheat bypass is explicitly out of scope and will not be implemented.
- Global hotkeys and input simulation rely on OS-level APIs; behavior may differ by platform.
